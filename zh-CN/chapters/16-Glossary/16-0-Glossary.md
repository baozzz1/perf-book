# 词汇表（Glossary）


**AOS** Array Of Structures（结构体数组）

**BB** Basic Block（基本块）

**BIOS** Basic Input Output System（基本输入输出系统）

**CI/CD** Contiguous Integration/ Contiguous Development（持续集成/持续开发）

**CFG** Control Flow Graph（控制流图）

**CP** Continuous Profiling（持续性能分析）

**CPI** Clocks Per Instruction（每指令时钟周期数）

**CPU** Central Processing Unit（中央处理器）

**DDD** Data-Driven Development（数据驱动开发）

**DSB** Decoded Stream Buffer（解码流缓冲区）

**DRAM** Dynamic Random-Access Memory（动态随机存取存储器）

**DTLB** Data Translation Lookaside Buffer（数据转换后备缓冲区）

**EBS** Event-Based Sampling（基于事件的采样）

**EHP** Explicit Huge Pages（显式大页）

**FLOPS** FLoating-point Operations Per Second（每秒浮点运算次数）

**FMA** Fused Multiply Add（融合乘加）

**FPGA** Field-Programmable Gate Array（现场可编程门阵列）

**GPU** Graphics processing unit（图形处理器）

**HFT** High-Frequency Trading（高频交易）

**HPC** High Performance Computing（高性能计算）

**I/O** Input/Output（输入/输出）

**IDE** Integrated Development Environment（集成开发环境）

**ILP** Instruction-Level Parallelism（指令级并行）

**IPC** Instructions Per Clock cycle（每时钟周期指令数）

**IPO** Inter-Procedural Optimizations（过程间优化）

**ITLB** Instruction Translation Lookaside Buffer（指令转换后备缓冲区）

**LBR** Last Branch Record（最近分支记录）

**LLC** Last Level Cache（末级缓存）

**LSD** Loop Stream Detector（循环流检测器）

**LTO** Link-Time Optimizations（链接时优化）

**MPI** Message Passing Interface（消息传递接口）

**MSR** Model Specific Register（型号特定寄存器）

**MS-ROM** Microcode Sequencer Read-Only Memory（微码定序器只读存储器）

**NUMA** Non-Uniform Memory Access（非一致性内存访问）

**OOO Execution** Out-of-Order Execution（乱序执行）

**OS** Operating System（操作系统）

**PEBS** Processor Event-Based Sampling（处理器基于事件的采样）

**PDB files** Program-Debug Data Base files（程序调试数据库文件）

**PGO** Profile-Guided Optimizations（基于性能分析的优化）

**PMC** Performance Monitoring Counter（性能监控计数器）

**PMI** Performance Monitoring Interrupt（性能监控中断）

**PMU** Performance Monitoring Unit（性能监控单元）

**PT** Processor Traces（处理器追踪）

**RAT** Register Alias Table（寄存器别名表）

**RNG** Random Number Generator（随机数生成器）

**ROB** ReOrder Buffer（重排序缓冲区）

**SIMD** Single Instruction Multiple Data（单指令多数据）

**SMT** Simultaneous MultiThreading（同步多线程）

**SOA** Structure Of Arrays（数组结构体）

**TLB** Translation Lookaside Buffer（转换后备缓冲区）

**TMA** Top-down Microarchitecture Analysis（自顶向下微架构分析）

**TSC** Time Stamp Counter（时间戳计数器）

**μop** MicroOperation（微操作）
